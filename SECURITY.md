# Security policy

Strongroom is alpha software that handles encryption keys and third-party credentials. It has not had an independent security audit; see [docs/security.md](docs/security.md) for its threat model and boundaries.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub security advisories](https://github.com/solcreek/strongroom/security/advisories/new). Do not open a public issue. Include the affected version or commit, the impact, and steps to reproduce. Never include real credentials, plaintext secrets or production envelopes.

Only the latest commit on `main` receives fixes during the alpha.
